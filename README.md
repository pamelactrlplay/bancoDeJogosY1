# Gerenciador de Banco de Dados de Jogos\

Um aplicativo desktop desenvolvido em **Python** utilizando **Tkinter** para a interface gráfica e **SQLite** para o armazenamento local de dados. Este projeto faz parte dos projetos contruidos em sala de aula pela turma de Young 1 - 2026/2.\

## Funcionalidades\

- **Cadastro de Jogos:** Adicione o título, gênero e plataforma de seus jogos favoritos.\
- **Listagem Dinâmica:** Visualização em tabela (Treeview) de todos os itens cadastrados.\
- **Filtro por Gênero:** Filtre rapidamente os jogos exibidos na tabela por categoria (Ação, Terror, Fantasia, Aventura, Infantil).\
- **Exclusão de Registros:** Remova jogos diretamente da interface com confirmação de segurança.\
- **Banco de Dados SQLite:** Persistência automática dos dados utilizando um banco local (`jogos.db`).\

## 🛠️ Tecnologias Utilizadas\

- Python 3\
- Tkinter (Interface Gráfica)\
- SQLite3 (Banco de Dados)\

## ⚙️ Como Executar o Projeto\

### Pré-requisitos\
Certifique-se de ter o Python 3 e o Tkinter instalados no seu sistema operacional (Linux/Ubuntu/Debian):\
bash\
sudo apt update\
sudo apt install python3-tk\

### Executando a aplicação\
1. Clone este repositório:\
bash\
git clone https://github.com/pamelactrlplay/bancoDeJogosY1.git\

2. Entre na pasta do projeto:\
bash\
cd bancoDeJogosY1\

3. Execute o script principal:\
bash\
python3 seu_arquivo.py\
